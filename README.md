# A-College-week
A student project providing information about college week events, activities and celebration

## About the Project
This project provides information about College Week celebrations and activities organised by the college.

## Objectives
- To share information about College Week.
- To inform students about upcoming events.
- To encourage student participation.

## Main Activities
-> Cultural programmes
-> Music and dance competitions
-> Sports activities
-> Literary competitions
-> Student performances

## Purpose
The purpose of this project is to keep students informed about College Week events and celebrations.
